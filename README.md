# Ithaka

Leesplanning voor 2027 als kleine web-app (PWA) voor de telefoon.

- Per maand een checklist, plus *Doorlopend* en een *Voorraad*.
- Afvinken, verplaatsen (lang indrukken en slepen, of via ⋯), verwijderen en toevoegen.
- Alles wordt alleen op het eigen apparaat bewaard (localStorage). Er gaat niets naar een server.
- Back-up: het pijltje rechtsboven geeft een code om te bewaren en terug te plakken.

Installeren: open de site in Chrome op Android → menu ⋮ → *App installeren* / *Toevoegen aan startscherm*.

Bestanden: `index.html` (de hele app), `manifest.webmanifest`, `sw.js` (offline), `icons/`.
